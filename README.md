# awesome-skills

个人 Agent Skills 集合。每个 skill 一个目录，入口文件为 `SKILL.md`。

## Skills

| Skill | 说明 |
| ----- | ---- |
| [git-commit](./git-commit/) | 按仓库提交规范分析改动并创建 commit |

## 新增 Skill

1. 新建目录：`mkdir <skill-name>`
2. 在目录内添加 `SKILL.md`（含 YAML frontmatter：`name`、`description`）
3. 提交并推送

可按需软链或复制到 Cursor / Claude 的 skills 目录使用。
